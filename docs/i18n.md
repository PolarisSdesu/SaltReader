# i18n 规范（简体中文 / 繁体中文 / English / 日本語）

## 语言与目录

- `values/`：**English**（默认回退）
- `values-zh-rCN/`：简体中文
- `values-zh-rTW/`：繁体中文（台湾用语，例如 資料夾、搜尋、設定、書櫃）
- `values-ja/`：日本語（自然 UI 用语，例如 フォルダ、検索、設定、ライブラリ）
- 每个模块一个资源文件，避免多人改同一个 XML：
  - `strings_common.xml`（Lead）：书籍格式、进度、元数据字段、筛选/排序/布局、通用短词
  - `strings_reader.xml`（reader）：阅读器/文字阅读器、工具栏、滑杆、加载/错误、无障碍描述
  - `strings_library.xml`（ui-saf）：书库、搜索、书卡、操作面板、导入提示
  - `strings_settings.xml`（i18n-settings）：设置各页、存储、关于、颜色选择器
  - `strings_data.xml`（data-saf）：导入/索引/扫描失败原因等用户可见文案
  - `strings_util.xml`（build-qa）：相对时间等工具文案
- 所有 4 个语言目录都要有同名文件，不得缺 key（缺失会导致英文回退，测试脚本会检查）。

## 命名与格式

- key 前缀用模块名 + 语义：`reader_loading_preparing`、`library_empty_title`、`settings_storage_indexed_books`。
- 带数量的文案：
  - 需要单复数时使用 `<plurals name="...">`，`en` 提供 `one`/`other`，中文/日文只提供 `other`。
  - 简单数字拼接用 `<string>` + `%1$d` / `%1$s` 位置参数，禁止字符串拼接构造语序。
- 不要在 Kotlin 里拼接中英文语序；用 `stringResource(R.string.x, args...)` 或 `context.getString(R.string.x, args...)`。
- 用户可见文案不允许保留硬编码中文；注释、日志（Log）、异常 message 可以保留中文/英文，但不得直接展示给用户。
- `contentDescription` 也必须走资源。
- 枚举标签（格式/筛选/排序/布局/阅读模式/方向/背景/主题）不要在枚举里存中文，改为 UI 层 `when` + 资源映射。

## 数据层文案

- `ImportFailure.reason` 等面向用户的失败原因必须来自 `context.getString(R.string.data_*)`；
  纯函数/无 Context 的地方返回错误码枚举，再由 Repository（有 Context）映射为文案。
- 不要把 log-only 文案抽成资源。

## 验证

### 自动化（随 CI 执行，缺失即失败）

`app/src/test/java/moe/gbxin/saltreader/i18n/I18nResourceConsistencyTest`：

1. 每个 `res/values/strings_*.xml` 必须在 `values-zh-rCN/`、`values-zh-rTW/`、`values-ja/`
   存在，且 key 集合**完全一致**（missing 与 extra 都失败），同一文件内不得有重复 key；
2. `res/xml/locales_config.xml` 必须恰好列出 `en`、`zh-CN`、`zh-TW`、`ja`。

跑法：

```bash
./gradlew :app:testDebugUnitTest
```

### 用户可见硬编码中文扫描

注释、`Log`、异常 message 允许保留中文；以下脚本去掉注释后检查 Kotlin 字面量 CJK，
用于人工复核（`Text(...)`/`contentDescription =` 等出现即应改为资源引用）：

```bash
python3 - <<'EOF'
import glob, re
CJK = re.compile(r'[\u4e00-\u9fff]')
hits = []
for f in glob.glob('app/src/main/java/**/*.kt', recursive=True):
    in_block = False
    for i, line in enumerate(open(f, encoding='utf-8'), 1):
        s = line
        while True:
            if in_block:
                j = s.find('*/')
                if j < 0:
                    s = ''
                    break
                s = s[j + 2:]
                in_block = False
            else:
                j = s.find('/*')
                if j < 0:
                    break
                k = s.find('*/', j + 2)
                if k < 0:
                    s = s[:j]
                    in_block = True
                    break
                s = s[:j] + s[k + 2:]
        s = s.split('//', 1)[0]
        if CJK.search(s):
            hits.append(f'{f}:{i}: {line.strip()}')
print(f'{len(hits)} candidate lines')
print('\n'.join(hits))
EOF
```
